# Datos

Esta carpeta está **vacía a propósito**.

Los datos de operación de una red de distribución de agua (caudales, cargas aguas arriba y aguas abajo de la válvula, curvas de las máquinas) pertenecen a quien opera la red. Por eso:

- **No se suben datos al repositorio sin permiso explícito** de su dueño.
- Los datos que use el proyecto están **disponibles bajo solicitud**, siempre que su dueño lo permita.
- Los valores que vengan de la literatura (por ejemplo, del paper base) se citan con su fuente en el documento de formulación, no se copian aquí como conjunto de datos.

Si vas a ejecutar el código con tus propios datos, ponlos en esta carpeta; `.gitignore` y esta nota están para recordar que no se deben publicar.
